# T01 fixture status demo

This demonstrates typed contracts and an honest status shell. It does not run a scanner, service, or USB policy.

## Prerequisites

- Rust 1.98.1; local GNU builds also need MinGW 16.2.0 on PATH. Windows CI uses MSVC build tools.
- Node 24 and pnpm 12.4.2.

## Run

```powershell
pnpm install --frozen-lockfile
cargo run -p sentinel-cli -- status --fixture
pnpm --dir apps/ui dev
```

Open the local Vite URL printed by the last command. Both surfaces consume `data/fixtures/status.json`. The CLI emits the typed JSON; the UI shows file scanning as unavailable and USB storage/HID gates as untested. The UI's technical-details disclosure shows the same fixture payload. Running `sentinel-cli` without `status --fixture` exits with a usage error; it cannot present fixture data as live status.

Run `./tools/verify.ps1` to check format, lint, Rust/TS tests, the UI build, and generated TypeScript drift. Physical USB and HID acceptance remain separate release gates.
