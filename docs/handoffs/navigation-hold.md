# Native extension navigation hold lifecycle — issue #14

Module apps/extension/src/navigation-hold.js is pure internal logic, not a live browser block/redirect. No permissions, DNR rules, fetching, popup or desktop transport enabled. GLM integrates after review and a registered host adapter exists.

Signatures: createNavigationHold({tabId,navigationId,assessmentId}, now, ttlMs) returns frozen snapshot; finishInspection(snapshot, sameSubject, reason, now) returns current snapshot; consumeContinuation(snapshot, sameSubject, now) returns next snapshot or null; invalidateHold(snapshot) returns current snapshot. Reasons accepted: unknown or potentially_harmful. State: held, continued_once, expired, invalidated. Coverage always partial, never safe. Initial reason inspection_required.

Use trusted extension tab/document events to allocate fresh process-local IDs, not page supplied identity. References are ASCII alphanumeric/_/- 1–64 chars; tab is nonnegative safe integer. now is a nonnegative safe integer monotonic tick (for example floored performance.now); ttl 1–300000ms. Reject invalid input with fixed TypeError. Clock regression/nonfinite/expiry seals state. Wall clock is unsuitable; restart must discard all sessions and invalidate old responses.

Example: hold=createNavigationHold({tabId:7,navigationId:'nav-1',assessmentId:'assessment-1'},100,500); hold=finishInspection(hold,hold.subject,'potentially_harmful',110). Render actual reason and partial coverage. Replace local handle with returned current snapshot; do not retain history. JSON contains only copied correlation fields/state/reason/coverage, no target URL/content. This is not an authoritative Rust DTO or request decoder.

Native owner WeakMap makes forged/JSON-copied/stale snapshots unusable for continuation. One inspection completion seals against replay/downgrade. Terminal states cannot be reopened. Different tab/navigation/assessment rejects stale results. Old results return current state; never render an old caller-held snapshot as authoritative. A null continuation is rejection, not allow. Adapter must own a bounded active-tab map and invalidate/release snapshots on navigation/tab close; WeakMap alone is not a global admission bound.

consumeContinuation is only lifecycle consumption AFTER authenticated user gesture and policy checks; it grants no browser allow itself. Host must bind actual target privately to same navigation, validate continuation policy, then perform exactly scoped navigation/rule operation. Do not expose arbitrary calls to content scripts or infer user consent from snapshot possession. An expired hold must remain blocked/unknown until explicit new inspection; null does not install allow rules.

Acceptance: node --test apps/extension/test/navigation-hold.test.mjs. Five tests cover subject binding, replay (including original snapshot), forged snapshot, inspection downgrade, terminal sealing, monotonic expiry, bounds, fixed path-free output. These synthetic state tests are not real browser interception, shortener resolution, popup or desktop event evidence. Full verifier recorded in PR.

Next integration: reviewed bounded native bridge/events, DNR hold/rule mapping and target/navigation binding, popup/desktop outbox, actual owned benign Chrome interception. Remote hostile fetching, valuable vault credentials and cloud content remain gated separately.

## Bounded native registry follow-up

`NavigationHoldRegistry` in src/navigation-registry.js is the preferred trusted owner. One host instance admits at most 32 tracked tabs, one current snapshot each, including terminal sessions until cleared. `begin(tabId,now,ttlMs)` returns a new hold or null on capacity/counter exhaustion; validates before replacing/invalidation. Internal fresh nav-N/assessment-N references never wrap. No caller reference or URL accepted. `read(tabId)` returns current snapshot/null; reading alone does not refresh expiry. `finish(subject,reason,now)` returns current observation or null for unmatched references; `continueOnce(currentSnapshot,now)` returns consumed snapshot/null and synchronizes expiry; `clear(tabId)` invalidates/removes and returns bool. Clear on trusted tab close/navigation away; replace on trusted new navigation.

Example: `const registry = new NavigationHoldRegistry(); const hold = registry.begin(7,100,500); const current = registry.finish(hold.subject,'potentially_harmful',110);`. Render current, not old hold. After independently validating actual user gesture, current target and policy, `registry.continueOnce(current,111)` consumes lifecycle once. It does not install any allow rule. A null admission is bounded unavailable/hold rejection, never permission to navigate or eviction of an active warning. Clear terminal slots explicitly. Registry counter is process-local; discard all handles on worker restart and reestablish browser rule state separately.

The module stores no target, credentials or content and registers no browser listener. Future target binding must be private and validated with browser-generated tab/document events; these references/snapshots are not remote authorization. Expose neither registry methods nor raw path/URL actions to content scripts. One registry per trusted service worker is an integration invariant; creating multiple registries bypasses this instance bound and may repeat reference text. JSON copied snapshots cannot continue. This registry is not durable storage or a generated cross-process DTO.

Five additional tests cover 32-tab capacity without eviction, replacement/clear invalidation, original/foreign-handle rejection, terminal/expiry behavior and invalid replacement preservation. Ten combined navigation tests and full verifier pass. No real browser/manual acceptance added by these tests. Next: reviewed bridge/event and privately target-bound browser adapter; keep native commands/permissions disabled until reviewed.

## Trusted expiry timer (5 October 2026)

`registry.expire(now): Snapshot[]` visits at most 32 tracked tabs and returns only newly expired current snapshots. Use the same trusted monotonic clock as begin/finish/continue. Invalid nonnegative-safe-integer time throws fixed `TypeError('invalid navigation clock')` before changing any entry. A clock rollback expires affected held authority. Terminal entries stay tracked until `clear`; timer polling does not silently evict a warning or reopen capacity. Repeated polls return no duplicate transition. `pollHoldExpiry(snapshot, now)` is the internal snapshot helper; it never marks an inspection completed.

Example: `const h = registry.begin(7, 100, 500); registry.expire(599)` returns `[]`; `registry.expire(600)` returns `[{subject:h.subject,state:'expired',reason:'inspection_required',coverage:'partial'}]`. `registry.read(7)` now returns that expired observation. `registry.continueOnce(h,601)` and continuation using the expired snapshot both return null. A prior inspected reason is preserved on expiry; polling an unexpired hold does not prevent a later on-time inspection from supplying its actual reason.

Adapter entry point: poll before reading/rendering a warning and from a bounded host-owned timer; replace rendered references with `read(tabId)`. Timer callbacks may be delayed or suspended, so display polling is not an interception guarantee. Finish/continue still check time independently. An expired warning stays expired/blocked or unknown; it must not install an allow rule. Restart discards process-local time/handles and requires reestablishing actual browser policy. Do not pass page-provided time into the registry. Polling emits only fixed correlation/state/reason metadata, never URLs or content. No DTO schema change or new browser listener/permission is included.

Four new tests were observed failing before the API existed, then passed with the implementation. Fourteen combined lifecycle/registry tests now pass: original admission/replay invariants plus exact-deadline idle expiry, no deadline extension, unsealed inspection, preserved reasons, cleared/replaced/continued exclusions, bounded unique batches, invalid-input preservation and rollback rejection. These are executable state tests, not real browser interception or desktop connectivity evidence.
