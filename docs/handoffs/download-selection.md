## Bounded native correlation decoder

`sentinel_agent::download_selection::decode_download_observation(bytes: &[u8]) -> Result<DownloadObservation, DownloadIngressError>` rejects inputs over 512 bytes before JSON parsing, rejects invalid/unknown fields, and calls semantic reference validation before returning. Errors are fixed `TooLarge` or `InvalidObservation`; no raw input or parser error is returned. This is an unconnected library helper, not an RPC endpoint. Transport still must cap frames before allocating and authenticate the retained session; no observation is stored here. It grants no approval/job/file access and does not implement progress/cancel. Reproduce with `cargo test -p sentinel-agent --test download_selection`. Failing-first missing-module test then successful focused run recorded; full verifier required at published head. Native approval/cleanup registry and all Windows/transport gates remain pending.

### Current ingress shape regression

The native helper requires a named JSON object. Serde's general struct decoder also accepts positional arrays; that form is rejected explicitly by this helper before decoding. Exactly 512 bytes including permitted JSON whitespace is accepted when otherwise valid; 513 bytes is rejected before parsing. Duplicate named fields, nested/non-string references, null/array roots and a 65-byte session reference are rejected. Focused regression and full unchanged verifier passed at 690092c, and both CI jobs passed. Direct DTO deserialization still requires the documented semantic validation; use the bounded native helper for this proposed ingress. No native transport is enabled.
