# Native v1 executable request validation — PR20 / issue #8

`sentinel_proto::native_request::validate_request(&[u8]) -> Result<NativeRequest, NativeRequestError>` validates JSON payload bytes AFTER the Chrome framing decoder and BEFORE dispatch. Do not convert to serde_json::Value first: that loses duplicate known payload fields. RawValue preserves the payload until typed decoding. Host must impose framing/read deadlines before allocating/reading and validate actual caller origin and user SID/session independently.

Only NativeRequest::Capabilities{id} and ::Url{id,subject_ref,url} can pass. No generic agent/USB/vault/file/execute forwarding. Full URL exists only in the validated private request; Debug redacts all payload. Never log/destructure URL into diagnostics or return it as subject. Error has fixed BadRequest/Oversized/UnsupportedMethod/UnsupportedVersion and optional validated correlation ID. Malformed known envelopes/payloads have no trusted ID. Structurally valid unsupported method/version may echo validated ID; unsupported version requires port closure. Unknown methods never dispatch.

Envelope exactly version/id/kind/payload, deny unknown/duplicate fields; version exactly major1/minor0. id and subjectRef 1–128 ASCII alphanumeric/_/-. URL max2048 scalars/8192 bytes, raw http(s):// authority, no credentials/@ authority/control/whitespace/backslash, parsed host required. Parsing performs no network/DNS/navigation. Known payloads deny unknown/duplicate fields; capabilities payload empty object only. Unknown-method payload is structurally an object and is never interpreted/forwarded. Input byte cap1MiB checked before JSON parse. Invalid UTF8/JSON returns no ID.

Examples in docs/proposals/native-host-contract-v1-draft.md remain authoritative review proposal. Code is internal validation, not a registered native host or generated UI wire DTO. It does not enforce32 pending, port IDs/replay/subject response correlation, timeouts, authentication or expiry. Those remain required host/extension integration. Existing native protocol allowlist remains unchanged; activity PR49 needs separately reviewed protocol extension.

Dependency change: reuse existing Cargo.lock url2 parser package in proto; enable existing serde_json raw_value feature to reject duplicate typed URL payload fields. Coordinator reviews shared dependency delta; no new downloaded library chosen. URL parser handles syntax, not reputation or private-network policy; arbitrary URL fetching remains disabled.

Acceptance: cargo test -p sentinel-proto --test native_request. Five tests cover both methods, root duplicate/unknown/invalid ID, valid unsupported method/version, credentials/controls/backslashes/malformed schemes/URL limit/frame cap, duplicate URL regression and redacted Debug. Full verifier recorded in evidence. Remaining live bridge/native registration/actual Chrome-desktop journey not claimed.
